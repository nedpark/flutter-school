# 플루터스쿨 (Flutter School) - 코딩 초보자를 위한 Dart & Flutter 완벽 가이드

> **"코딩이 완전 처음이어도 괜찮습니다!"**  
> 이 강의 자료는 프로그래밍이나 앱 개발을 한 번도 해보지 않은 분들을 위해, 어려운 전문 용어 대신 **실생활 비유**와 **친절한 단계별 설명**으로 구성된 입문서입니다.

별도의 복잡한 개발 프로그램(VS Code, Android Studio 등)을 컴퓨터에 설치할 필요 없이, 웹 브라우저만 켜서 [DartPad](https://dartpad.dev/) 웹사이트에서 모든 실습 코드를 바로 따라 해볼 수 있습니다.

---

## 🧭 DartPad 사용 안내

[DartPad(https://dartpad.dev/)](https://dartpad.dev/)는 웹 브라우저에서 Dart 언어와 Flutter 코드를 작성하고 실시간으로 실행해볼 수 있는 온라인 실습 도구입니다.

- **화면 왼쪽 (Editor)**: 코드를 직접 작성하거나 복사해 넣는 작업 공간입니다.
- **화면 오른쪽 (Output)**:
  - **Dart 모드 (Day 1~5)**: 텍스트 콘솔 창으로 실행 결과가 나타납니다.
  - **Flutter 모드 (Day 6~10)**: 스마트폰 형태의 실제 앱 화면이 실시간으로 렌더링됩니다.
- **실행 버튼 [ ▶ Run ]**: 화면 상단의 파란색 버튼을 누르면 작성한 코드가 즉시 실행됩니다.
- **모드 전환 방법**: 우측 상단 `New Pad` 클릭 후 실습에 맞춰 **Dart** 또는 **Flutter**를 선택합니다.
